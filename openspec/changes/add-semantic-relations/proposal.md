# Proposal: Add Semantic Relations

**Change ID:** `add-semantic-relations`
**Type:** New Capability
**Status:** Proposed
**Depends On:** `add-concept-resource-entities`

## Why
Enable users to create meaningful, typed connections between concepts and resources (EXEMPLIFIES, EXPLAINS, REQUIRES, etc.).

## What Changes
- Add relation creation endpoints for each semantic type
- Document standard relation types: EXEMPLIFIES, EXPLAINS, DEFINES, SPECIFIES, CRITIQUES, REQUIRES, IS_A, PART_OF, RELATED_TO, SUPERSEDES
- Update UI to support creating connections with relation types

## Impact
Implements "Connect Resources to Concepts" and "Structure Concept Relationships" requirements from knowledge-organization spec.
